# NeetCode Challenges 🚀

Welcome to the **NeetCode Challenges** repository! This repository contains my solutions and notes for various NeetCode challenges. These exercises are designed to strengthen Python fundamentals, improve problem-solving skills, and prepare for technical data structures and algorithms interviews.

## 📚 Topics Covered

The challenges in this repository are categorized by the following core concepts:

- **Arrays & Hashing**: Fundamentals of working with arrays, lists, dictionaries/hash maps, and sets.
- **Two Pointers**: Techniques involving multiple pointers to solve array and string problems efficiently in linear time.
- **Stack**: Problems solved using Last-In-First-Out (LIFO) data structures.
- **Linked List**: Manipulation of singly and doubly linked lists (reversing, merging, cycle detection).
- **Binary Search**: Efficient searching in sorted arrays and finding optimal solutions.
- **Sliding Window**: Managing dynamic windows over arrays/strings to track subsets of data.
- **Trees**: Operations on Binary Trees, Binary Search Trees (BST), traversals, and depth/breadth-first search.

## 🛠️ Language & Tools

- **Language:** Python 3
- **Focus:** Data Structures and Algorithms

## 🚀 How to Use This Repository

Each directory corresponds to a specific topic and contains Python files with the solutions. Feel free to explore the folders, review the code, and use them as a reference for your own learning!
